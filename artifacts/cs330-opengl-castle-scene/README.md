# CS 330 OpenGL Castle Scene

This folder contains the software engineering and design artifact.

- `original/` contains the original `SceneManager.cpp` selected for the code review.
- `enhanced/` contains the enhanced configuration and logging components.
- `narrative.md` provides the web version of the enhancement narrative.

The complete submitted artifact package, including the enhanced `SceneManager.cpp` and PDF/Word narrative files, is included in the final portfolio submission package.
